# Project rules
- Keep wedding dates, venue, timeline milestones, and schedule in a shared wedding data module so sections stay consistent.
- Interpret event times in Asia/Kolkata; use an explicit UTC offset for countdown targets so guests see the same countdown worldwide.
- Store event descriptions, Marathi lines, attire guidance, and image references alongside each event in shared wedding data so the schedule renders consistently.
- Apply the shared language-aware typography to Marathi text; serve its font locally so bilingual sections use consistent metrics without relying on system fallback fonts.
